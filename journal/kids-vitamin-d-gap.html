～50%小孩 Vitamin D 不足，父母却一直在买「免疫力保健品」？

21 Aug 20262 min readSKINPIENS · Navy + Cream

越来越多研究显示缺乏Vit D是导致小孩免疫力低落的原因之一，…

很多爸妈一听到孩子容易生病、伤风感冒，第一反应就是：

“是不是免疫力不好？”

“要不要买点 Vitamin C、益生菌？”

但有一个很基础、却常常被忽略的营养素——

Vitamin D。

越来越多研究显示缺乏Vit D是导致小孩免疫力低落的原因之一，

如果只顾补充免疫力保健品，

却忽略了本身Vit D的缺乏，

就会一直补补补，可是孩子还是一直弱弱弱。

马来西亚明明天天有太阳，

但研究却发现，接近一半的儿童 Vitamin D 水平不足。

为什么？

因为现在的小朋友很多时间都在室内。

上课、补习、看 iPad、吹冷气，

真正晒到太阳、在户外跑跳的时间反而越来越少。

而 Vitamin D 不只是“顾骨头”。

它也参与身体正常的免疫功能、骨骼发育和钙吸收。

那怎么知道孩子 Vitamin D 够不够？

最直接的方法，

👉 是抽血检查25-hydroxyvitamin D［25(OH)D］。

不过要注意——

不一定要先验血，才可以补充 Vitamin D。

如果孩子整体健康，只是做日常、一般剂量的营养补充，

通常不需要为了“先验才补”而特地去抽血。

身体每天都会使用Vit D，吃回每日建议的份量就好。

但如果孩子长期少晒太阳、严重挑食，或本身有其他健康风险，

才需要先跟医生讨论是否需要验血，再决定补充剂量。

尤其是高剂量 Vitamin D，不建议自己长期乱补。

所以爸妈在一直加各种“免疫力配方”之前，

几千块几千块的买，

不如先看看这些基础有没有顾好：

🥚 有没有摄取足够的 Vitamin D

🥛 整体营养够不够

☀️ 有没有适时的户外活动活动

😴 睡眠有没有顾好

保健品不是不能吃。

但先把基础补齐，再谈而外补充，

不然真的就是本末倒置。
